# Lesson 09: Responsive Design

**Learn:** The grid uses `auto-fit` and `minmax(180px, 1fr)` to fit as many cards as possible in each row. Each card stays at least 180px wide, and extra space is shared equally. No media query is needed.

1. Open [the example](index.html) in a browser.
2. Resize the window and watch the cards wrap. Change `180px` to `250px` and resize again.
3. After lesson 10, complete activity [02 Build a responsive layout](../../activities/02-build-a-responsive-layout/README.md).

**Tesla connection:** Use this idea in the [final project](../../../index.html#final-project), which combines page structure, styles, Tailwind classes, and JavaScript controls.
