# Lesson 05: Flexbox

**Learn:** `display: flex` puts the three boxes in a row. `justify-content: space-between` spreads them across the row, `align-items: center` centers them vertically, and `gap` keeps space between them.

1. Open [the example](index.html) in a browser.
2. Change `justify-content` to `center`, then change `align-items` to `flex-start`. Refresh after each change to see what moves.
3. After lesson 05, complete activity [01 Style a Model 3 card](../../activities/01-style-a-model-card/README.md).

**Tesla connection:** Use this idea in the [final project](../../../index.html#final-project), which combines page structure, styles, Tailwind classes, and JavaScript controls.
