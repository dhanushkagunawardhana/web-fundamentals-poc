# Lesson 02: Colors And Typography

**Learn:** Compare dark, muted, blue, green, and white text. The examples also show `font-size`, `font-weight`, `line-height`, `letter-spacing`, `text-transform`, and `font-style`. The dark highlight uses `background-color` to contrast with white text.

1. Open [the example](index.html) in a browser.
2. Change the label's `color` and `letter-spacing`, then change the intro's `font-size` and `line-height`. Refresh after each change.
3. After lesson 05, complete activity [01 Style a Model 3 card](../../activities/01-style-a-model-card/README.md).

**Tesla connection:** Use this idea in the [final project](../../../index.html#final-project), which combines page structure, styles, Tailwind classes, and JavaScript controls.
