# Lesson 06: Positioning And Layers

**Learn:** `position: relative` moves an element from its normal place while keeping its space. An absolutely positioned element uses the nearest positioned parent as its reference. The badge sits over the card without taking up space in the card's normal layout.

1. Open [the example](index.html) in a browser.
2. Change `.relative-box`'s `top` value and refresh. Then change `.badge`'s `top` or `right` value.
3. After lesson 10, complete activity [02 Build a responsive layout](../../activities/02-build-a-responsive-layout/README.md).

**Tesla connection:** Use this idea in the [final project](../../../index.html#final-project), which combines page structure, styles, Tailwind classes, and JavaScript controls.
