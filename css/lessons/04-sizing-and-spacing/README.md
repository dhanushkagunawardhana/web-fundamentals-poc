# Lesson 04: Sizing And Spacing

**Learn:** `width: 90%` lets the card change with the window, while `max-width: 400px` stops it from growing too wide. `margin: 32px auto` adds space above and below and centers the card. `padding: 24px` adds space inside it.

1. Open [the example](index.html) in a browser.
2. Resize the window. Then change `max-width`, `margin`, and `padding` one at a time and refresh to see the effect.
3. After lesson 05, complete activity [01 Style a Model 3 card](../../activities/01-style-a-model-card/README.md).

**Tesla connection:** Use this idea in the [final project](../../../index.html#final-project), which combines page structure, styles, Tailwind classes, and JavaScript controls.
