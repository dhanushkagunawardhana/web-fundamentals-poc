# Activity 02: Build an interactive model picker

**Use lessons 06–10.** Use DOM selection, events, modern array methods, and localStorage to switch models and remember the selection.

1. Give students the [task folder](task/) and open [its starter page](task/index.html) in a browser.
2. Edit the TODO and refresh to check the work.
3. Use the [worked solution](solution/index.html) to teach one implementation after students try it.

**Done when:** The page demonstrates all the listed skills and the student can explain the changes.
