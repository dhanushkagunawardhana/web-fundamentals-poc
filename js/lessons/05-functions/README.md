# Lesson 05: Functions

**Learn:** A function groups reusable steps and may return a value.

The inline `<script type="module">` is in `<head>`. The browser runs it after parsing the HTML, so it can find `#output`.

1. Open [the example](index.html) in a browser.
2. Find the code that demonstrates this idea; change one value and refresh.
3. After lesson 05, complete activity [01 Build a model data summary](../../activities/01-model-data-summary/README.md).
