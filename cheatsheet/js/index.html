Quick syntax reference

Use these small patterns in a script. The sections below show how they work together.

Syntax What it does Example
"text", 321, true Represent a string, number, or boolean. const ready = true;
typeof value Checks a value's type. typeof 321
const, let Create a fixed or reassignable binding. let count = 0;
+, += Add values or update a number. count += 1;
===, >= Compare values or numbers. range >= 320
if (...) { ... } else { ... } Choose between two actions. if (ready) { start(); }
`...${value}...` Insert a value into a string. `Range: ${range}`
[...], items[0] Store ordered values and read the first. const models = ["Model 3"];
{ key: value }, obj.key Store and read named values. car.range
function name(arg) { ... } Define reusable steps. function add(a, b) { return a + b; }
return value Send a result back from a function. return count;
() => { ... } Write an arrow function, often for callbacks or closures. () => count + 1
document.querySelector(...) Find one element in the page. document.querySelector("#output")
element.textContent Read or change an element's text. output.textContent = "Ready";
element.setAttribute(...) Change an HTML attribute. image.setAttribute("alt", "Red car");
addEventListener(...) Run code when an event occurs. button.addEventListener("click", show);
const { name } = car Read a property by destructuring. const { range } = car;
map, filter, find Transform, keep, or locate array items. models.map((m) => m.name)
localStorage.getItem(key) Read a saved string or get null. localStorage.getItem("model")
localStorage.setItem(key, value) Save a string across refreshes. localStorage.setItem("model", "Model 3")

Values and data types

Strings hold text, numbers hold numeric values, and booleans are true or false. An inline module in <head> runs after the page is parsed. 

<script type="module">
  const model = "Model 3"; // string
  const range = 321;      // number
  const available = true; // boolean
  document.querySelector("#output").textContent = model;
</script>

Variables and operators

const is a binding that cannot be reassigned; let can be reassigned. Operators calculate values, and template literals build strings. 

const range = 321;
let bonus = 25;
const total = range + bonus;
const message = `Estimated range: ${total} miles`;

Conditions

An if statement runs one branch when its condition is true and another otherwise. >= means greater than or equal to. 

const range = 321;
let label;
if (range >= 320) {
  label = "Long range";
} else {
  label = "Standard range";
}

Arrays and objects

An array holds items in order; use a zero based index to read one. An object groups named properties. 

const models = ["Model 3", "Performance"];
const first = models[0];
const car = { name: "Model 3", range: 321 };
const name = car.name;

Functions

A function accepts inputs called parameters and can return a result. Call it with an argument. 

function formatRange(miles) {
  return `${miles} mi`;
}
const text = formatRange(321);

Scope and closures

A variable declared inside a function stays in that function's scope. A returned function can remember it; this is a closure. Load a separate main.js with defer in <head>. Put the JavaScript below in that file. 

<script src="main.js" defer></script>

function makeCounter() {
  let count = 0;
  return () => {
    count += 1;
    return count;
  };
}
const next = makeCounter();
next(); // 1

DOM selection and updates

querySelector finds an element with a CSS selector. Change textContent for text or use setAttribute for an attribute. 

const heading = document.querySelector("#title");
heading.textContent = "Model 3 Performance";
const image = document.querySelector("#car-image");
image.setAttribute("alt", "Red Model 3");

Events

addEventListener runs a function when an event happens. Use a button click to update the page or switch a tab. 

const button = document.querySelector("#action");
const output = document.querySelector("#output");
button.addEventListener("click", () => {
  output.textContent = "Performance selected";
});

ES6+ and functional array methods

Destructuring reads object properties. filter keeps matching items, map transforms each item, and find returns the first match. 

const models = [{ name: "Model 3", range: 321 }];
const { name, range } = models[0];
const longRange = models.filter(({ range }) => range > 300);
const names = models.map(({ name }) => name);
const chosen = models.find(({ name }) => name === "Model 3");

Local storage

localStorage saves strings for the same site across refreshes. Read with getItem and write with setItem. A missing key returns null. 

const saved = localStorage.getItem("preferredModel") || "Model 3";
localStorage.setItem("preferredModel", "Performance");
