Tailwind CSS cheatsheet

HTML CSS JavaScript

Tailwind utilities are short class names that apply styles. The CDN setup shown below needs an internet connection; this cheatsheet itself does not.

Quick utility reference

Add these classes directly to HTML elements. The examples below use the same utility names as the practice pages.

Syntax What it does Example
text-4xl, text-lg Set text size. class="text-4xl"
font-bold, font-semibold Set text weight. class="font-bold"
text-slate-900, text-white Set text color. class="text-white"
text-center Center text. class="text-center"
p-4, px-5, py-16 Add padding on all, horizontal, or vertical sides. class="px-5 py-16"
mt-4, mt-6 Add top margin. class="mt-4"
mx-auto Center a width limited block horizontally. class="mx-auto max-w-3xl"
max-w-xl, max-w-4xl Limit width. class="max-w-xl"
flex, items-center Make a flex row and center items across it. class="flex items-center"
justify-between, gap-4 Spread items apart and set a gap. class="justify-between gap-4"
grid, grid-cols-2 Make a two column grid. class="grid grid-cols-2"
bg-slate-100, bg-blue-600 Set background color. class="bg-blue-600"
border, border-slate-200 Add and color a border. class="border border-slate-200"
rounded, rounded-lg Round corners. class="rounded-lg"
inline-block Keep an element inline while allowing box spacing. class="inline-block px-6"
hover:bg-blue-700 Change background on hover. class="hover:bg-blue-700"
focus-visible:outline Show a keyboard focus outline. class="focus-visible:outline"
md:grid-cols-2 Use two columns at the medium breakpoint and wider. class="grid-cols-1 md:grid-cols-2"

Setup and utility classes

Load Tailwind from the CDN in <head>. Put utilities in the HTML class attribute; each class changes a small part of the style. 

<head>
  <script src="https://cdn.tailwindcss.com"></script>
</head>
<h1 class="text-4xl font-bold">Model 3</h1>

Typography and color

text-4xl changes size, font-semibold changes weight, and text-slate-900 changes text color. 

<h1 class="text-4xl font-semibold text-slate-900">Model 3</h1>
<p class="text-lg text-slate-600">Electric sedan</p>

Spacing and sizing

p- adds padding, m- adds margin, and max-w- limits width. Direction letters include x, y, and t. 

<section class="mx-auto max-w-3xl px-5 py-16">
  <h1>Model 3</h1>
  <p class="mt-4">Meet the car.</p>
</section>

Flex utilities

flex creates a flex row. The other classes align items, spread them apart, and add a gap. 

<nav class="flex items-center justify-between gap-4 p-4">
  <strong>TESLA</strong>
  <a href="#specs">Specs</a>
</nav>

Grid utilities

grid creates a grid, grid-cols-2 makes two equal columns, and gap-4 separates them. 

<div class="grid grid-cols-2 gap-4">
  <div class="p-5">Image area</div>
  <div class="p-5">Feature copy</div>
</div>

Backgrounds and borders

bg- sets a background, border adds a border, and rounded-lg rounds corners. 

<section class="rounded-lg border border-slate-200 bg-slate-50 p-6">
  Feature
</section>

Hover and focus states

Prefix a utility with hover: or focus-visible: to apply it only in that state. A focus outline helps keyboard users see the active control. 

<button class="bg-blue-600 text-white hover:bg-blue-700
  focus-visible:outline focus-visible:outline-2">
  Explore
</button>

Responsive prefixes

Start with one column. md: applies the two column utility at Tailwind's medium breakpoint and wider. 

<div class="grid grid-cols-1 gap-4 md:grid-cols-2">
  <div>Image</div><div>Copy</div>
</div>

Combining utilities into sections

Build a section by combining width, spacing, alignment, typography, and button utilities on the elements that need them. 

<section class="mx-auto max-w-4xl px-5 py-16 text-center">
  <h1 class="text-4xl font-semibold text-slate-900">Model 3</h1>
  <p class="mt-4 text-slate-600">Electric sedan</p>
  <a class="mt-6 inline-block rounded bg-blue-600 px-6 py-3 text-white"
     href="#specs">See specs</a>
</section>

Tesla page styling

Reuse the same utility patterns for navigation, a hero, and specification cards. 

<nav class="flex justify-between bg-slate-900 p-4 text-white">...</nav>
<section class="bg-slate-100 px-5 py-16 text-center">
  <h1 class="text-4xl font-semibold">Model 3 Specs</h1>
  <div class="mx-auto mt-6 grid max-w-xl grid-cols-2 gap-4">
    <p class="rounded bg-white p-4">321 mi</p>
    <p class="rounded bg-white p-4">5 seats</p>
  </div>
</section>
