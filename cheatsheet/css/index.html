CSS cheatsheet

Quick syntax reference

Write a selector, then declarations inside braces. Change one value at a time and refresh the page.

Syntax What it does Example
style="..." Styles one HTML element. style="color: blue"
.class { ... } Styles elements with that class. .card { padding: 24px; }
color Sets text color. color: #171a20;
background-color Sets background color. background-color: #f4f4f4;
font-family Chooses the typeface. font-family: Arial, sans-serif;
font-size, font-weight Set text size and boldness. font-size: 24px;
line-height, letter-spacing Space lines and letters. line-height: 30px;
text-align, text-transform, font-style Align, change letter case, or italicize text. text-align: center;
padding, margin Add space inside or outside the border. padding: 16px;
border, border-radius Add and round a border. border: 1px solid #ddd;
width, max-width Set a flexible width and its limit. width: 90%; max-width: 400px;
display: flex Places items along one axis. display: flex;
justify-content, align-items Align flex or grid items along their axes. justify-content: space-between;
gap Adds space between flex or grid items. gap: 16px;
position: relative Moves an element while keeping its normal space; also anchors absolute children. position: relative; top: 20px;
position: absolute Places an element relative to a positioned ancestor. position: absolute; right: 8px;
display: grid Creates rows and columns. display: grid;
grid-template-columns Defines grid column widths. grid-template-columns: 2fr 1fr;
repeat(auto-fit, minmax(...)) Fits as many flexible columns as space permits. repeat(auto-fit, minmax(180px, 1fr))
@media (min-width: ...) Applies rules at or above a viewport width. @media (min-width: 700px) { ... }

Where CSS goes

A declaration has a property and value. Inline styles affect one element; a class rule can style many elements. A linked file keeps CSS separate from HTML. 

<p style="color: blue;">Inline style</p>

<style>
  .note { color: blue; }
</style>
<p class="note">Class rule</p>

<link rel="stylesheet" href="styles.css" />

Colors and typography

color sets text color; background-color sets the background. Size, weight, line height, spacing, case, and style shape the text. 

.heading {
  color: #171a20;
  background-color: #f4f4f4;
  font-family: Arial, sans-serif;
  font-size: 40px;
  font-weight: 700;
  line-height: 48px;
  letter-spacing: 2px;
  text-transform: uppercase;
  font-style: italic;
}

Box model

Content sits inside padding, border, and margin. Padding is inside the border; margin is outside it. 

.card {
  padding: 24px;
  border: 4px solid #3b82f6;
  margin: 32px;
}

Sizing and spacing

A percentage width changes with the parent. max-width limits growth. Auto side margins center a block with a limited width. 

.card {
  width: 90%;
  max-width: 400px;
  margin: 32px auto;
  padding: 24px;
}

Flexbox

Flexbox places items along one main axis. justify-content controls that axis; align-items controls the other axis. 

.specs {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}

Relative and absolute positioning

A relative element moves from its normal place but keeps that space. An absolute element is placed against its nearest positioned ancestor and leaves normal flow. 

.model-card { position: relative; }
.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}
.shifted { position: relative; top: 20px; }

Grid basics

Grid creates rows and columns. 1fr is one share of available space; items make new rows as needed. 

.grid {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 16px;
}

Grid page sections

Use unequal fractions for a wider visual column and a narrower text column. Reuse the same class for repeated sections. 

.feature {
  display: grid;
  grid-template-columns: 2fr 1fr;
  gap: 16px;
  align-items: center;
}

Flexible grids

auto-fit fits as many columns as will fit. minmax gives each one a minimum width and lets it grow. 

.features {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(180px, 1fr));
  gap: 16px;
}

Media queries

Start with one column. At a viewport width of 700px or more, use two columns. 

.models { display: grid; grid-template-columns: 1fr; }
@media (min-width: 700px) {
  .models { grid-template-columns: 1fr 1fr; }
}
