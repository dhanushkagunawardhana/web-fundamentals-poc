Quick syntax reference

Use the examples below as patterns. Replace the sample text and paths with your own.

Syntax What it does Example
<!doctype html> Declares an HTML document. <!doctype html>
<html lang="en"> Wraps the page and declares its language. <html lang="en">
<head>, <meta>, <title> Holds page metadata and the browser tab title. <title>Model 3</title>
<body> Holds visible page content. <body>Hello</body>
<h1>–<h6>, <p> Structure headings and paragraphs. <h1>Model 3</h1>
<strong>, <em> Mark important or emphasized text. <strong>Important</strong>
<a href="..."> Links to a page or a matching section ID. <a href="#specs">Specs</a>
<img src="..." alt="..."> Shows an image with alternative text. <img src="car.jpg" alt="Red car" />
<ul>, <ol>, <li> Make unordered or numbered lists. <ul><li>Range</li></ul>
<header>, <nav>, <main>, <footer> Name major page regions. <main>Content</main>
<section>, <article> Group a topic or self-contained item. <section><h2>Specs</h2></section>
<div>, <span> Group content when no semantic element fits. <span>321 mi</span>
<label for="...">, <input id="..."> Give a form control a visible label. <label for="q">Search</label>
<button type="button"> Creates a button that does not submit a form. <button type="button">Next</button>
id, class, aria-label Identify an element, group styling targets, or supply an accessible name. <nav aria-label="Main">

Page skeleton

The doctype starts an HTML document. Metadata belongs in <head>; visible content belongs in <body>. 

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1" />
    <title>Model 3</title>
  </head>
  <body>Hello!</body>
</html>

Text and headings

Use one main h1, then h2 for major sections. Paragraphs hold ordinary text. 

<h1>Model 3</h1>
<h2>Range</h2>
<p>Drive up to 321 miles.</p>

Links and navigation

A fragment link points to an element with the matching id. 

<nav aria-label="Page sections">
  <a href="#specs">Specs</a>
</nav>
<section id="specs"><h2>Specs</h2></section>

Images and alt text

src is the image path. alt describes meaningful content for people who cannot see the image. 

<img src="car.jpg" alt="Silver Model 3 parked beside a road" />

Lists

Use ul when order does not matter and ol for steps or rankings. Each item is an li. 

<ul><li>Range</li><li>Safety</li></ul>
<ol><li>Choose a model</li><li>Order</li></ol>

Semantic landmarks

Landmarks describe the page's major regions. A page normally has one main. 

<header><nav aria-label="Main">...</nav></header>
<main>Page content</main>
<footer>Contact details</footer>

Sections and articles

A section groups a topic, usually with a heading. An article can make sense on its own. 

<section aria-labelledby="features-title">
  <h2 id="features-title">Features</h2>
  <article><h3>Charging</h3><p>Charge at home.</p></article>
</section>

Buttons and forms

A button performs an action. Match a label's for to an input's id. 

<form>
  <label for="model">Choose a model</label>
  <select id="model" name="model">
    <option>Model 3</option>
  </select>
  <button type="submit">Continue</button>
</form>

Accessible structure

Keep headings in order, give controls visible labels, and write useful image descriptions. Label each navigation region when there is more than one. 

<h1>Model 3</h1>
<h2>Interior</h2>
<img src="interior.jpg" alt="Model 3 front seats and dashboard" />
<button type="button" aria-label="Next image">→</button>

Tesla page outline

Assemble semantic regions before styling the final page.

<header><nav aria-label="Main">...</nav></header>
<main>
  <section aria-labelledby="hero-title">
    <h1 id="hero-title">Model 3</h1>
  </section>
  <section aria-labelledby="features-title">
    <h2 id="features-title">Features</h2>
  </section>
  <section aria-labelledby="specs-title">
    <h2 id="specs-title">Specs</h2>
  </section>
</main>
<footer>...</footer>
