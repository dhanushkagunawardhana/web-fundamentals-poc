# Lesson 10: Custom Theme Colors

**Learn:** Add primary and secondary shades (100 and 200) with `theme.extend`,
then use them with Tailwind utilities.

1. Open [the example](index.html) in a browser.
2. Find the code that demonstrates this idea; change one value and refresh.
3. After lesson 10, complete activity [02 Style Tesla sections with Tailwind](../../activities/02-style-tesla-sections/README.md).

**Tesla connection:** Use a consistent primary and secondary palette
throughout the [final project](../../../index.html#final-project).
