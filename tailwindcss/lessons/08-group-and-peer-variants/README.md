# Lesson 08: Group and Peer Variants

**Learn:** Use `group-*` and `peer-*` variants to style elements based on a
parent or sibling state.

1. Open [the example](index.html) in a browser.
2. Find the code that demonstrates this idea; change one value and refresh.
3. After lesson 10, complete activity [02 Style Tesla sections with Tailwind](../../activities/02-style-tesla-sections/README.md).

**Tesla connection:** Use these variants for interactive cards and controls in
the [final project](../../../index.html#final-project).
